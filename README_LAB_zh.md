# SHODAN 数值编辑器 3.2.0

完整解压，双击 **SHODAN 数值编辑器.exe**。无需浏览器、Python 或 MCP。

底部「深色模式 / 浅色模式」可随时切换并记住偏好。深色模式使用纯黑主背景、纯黑输入框与纯黑面板（#000000）。

左侧选择区全部采用固定分页，只用上一页 / 下一页切换，不再响应滚轮或拖动。状态效果、附加配备、投送倒计时、飞鹰航程与载具回血均在对应的数据修改列表中操作，不再重复设置顶部快捷按钮。

## 使用

- 选择装备后，点击数值直接输入。更换弹丸通过中文名称列表选择。
- 点击搜索框输入名称或型号，支持中文输入、英文和 Ctrl+V 粘贴。
- 顶部「护甲」为唯一护甲入口。勾选多个被动；「修改数值」进入二级页，只显示对应的部分已命名项目。
- 关闭游戏，点击底部「写入游戏」。成功、失败、游戏仍在运行或无需写入时都会弹出结果。
- 配置会保存，但只有点击写入游戏才会改动游戏文件。恢复备份还原的是编辑器保存的版本，可能包含此前的 Mod。

程序沿用原项目的自动搜索：读取 Steam 注册表与 libraryfolders.vdf，查找各个游戏库。安装包不包含任何个人游戏路径。确需手动指定时，可在程序旁新建 `game folder.txt`，填写包含 data 文件夹的游戏安装目录。

页面提供淡入过渡、选项卡滑动光轨、悬停流光、勾选脉冲与写入进度光带；已移除扫描线和右上角装饰绿点。动效不阻止操作；系统关闭客户端动画时停止动效。

## 官方 3.2.0 更新

新增按名称选择状态效果、附加战略配备，载具生命恢复与延迟，投送倒计时及飞鹰接近距离和速度；修复部分武器弹丸与状态效果映射。护甲叠加按效果 ID 去重以避免军械库预览崩溃。窗口支持多屏适配并记住位置。
