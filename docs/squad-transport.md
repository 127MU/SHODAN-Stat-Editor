# 小队运输载体参数

依据：[SQUAD-TRANSPORT-26251122](https://github.com/deepseekv41flash/hd2-datamined/blob/master/docs/tables/SQUAD-TRANSPORT-26251122.md)。当前实现按组件类型 `0xD2B93CD8`、实体键和 168 字节记录定位，不使用文档的绝对地址。

六个载体的已有页面增加“小队投放（实验性）”分类。没有已有入口的载体在“载具与机甲”下补充“小队运输”条目；已有敌人页面继续使用其原入口。

每个载体提供 25 个字段：两个原始整数、一个节点名哈希、一个浮点参数、五个独立字节标记、一个模式原始值、六组资源引用与浮点参数，以及三个原始掩码。

六个资源槽各占 16 字节。前 8 字节为资源引用，后面的四字节参数采用浮点解释；槽尾四字节不修改。没有把这些参数误读成另外六条资源。末尾未定位部分也不开放编辑。

节点哈希的名称已经离线确认；规模、间距、枚举和掩码的含义尚未完成实机验证，因此保留原始偏移和实验性提示，不提供数量或延迟预设。资源替换仍需要相应资源被加载，也不能代替 AI 的投放逻辑。

此功能不会自动改写 SEAF 穿梭机的行为编号，不承诺修复其投空问题。编辑后仍通过“写入游戏”安装；新增入口默认不改变任何值。
