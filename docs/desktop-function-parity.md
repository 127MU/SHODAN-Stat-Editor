# 桌面重构功能保留清单（历史记录）

本文保留早期迁移时的验收状态，不代表 r5.1 当前缺失项。当前入口见[编辑流程](editing-workflow.md)、[预设库](preset-library.md)和[开发指南](development-guide.md)。第三人称准星现由武器参数编辑，游戏参数页已去除重复入口。

以重构前的 `desktop/huskar` 页面和后端接口作为对照。用户明确移除的变种及其代理不在保留范围；其余功能不能因为更换语言或界面而直接删除。

## 本轮已恢复并测试

- 参数页工具栏：装备预设、修改记录、射击引用链、资源诊断、撤销、重做、恢复本项。
- 引用链与资源报告支持独立搜索、导出，引用链可打开对应数据记录。
- 参数共享影响查询与“仅已修改”；工具栏保持一行，宽度不足时横向滚动。
- 游戏参数独立分类：第三人称准星、策略球部署限制、射弹与植被交互、受击与布娃娃补丁确认。
- 恢复原版入口，使用结构化恢复结果和进度弹窗。
- 列表搜索与参数搜索独立；返回列表保留查询，进入其他条目清空参数查询。
- 列表主页“仅已修改”筛选；返回列表重新读取条目修改标记，刚编辑的装备立即可筛选。
- 同一机甲、载具及敌人的关联条目按父项合成目录卡片，点击“选择打开”弹出部件列表；搜索与仅已修改仍匹配组内条目，普通武器独立展示。
- 参数数据准备好后一次切换，加载期间保留原页面。
- 标题栏与背景统一，Windows 11 原生圆角和边缘缩放；拖动缩放期间暂停滤镜、阴影和材质交互动效，保持输入控件状态，结束后恢复。

性能回归：导航摘要不扫描全部共享引用，也不检查资源补丁；打开资源分类时读取实际补丁状态。“待检查”不是“未安装”，未完成检查时不伪造状态。旧 `rows` 接口保留完整行为。
