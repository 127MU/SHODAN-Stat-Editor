# 无人机武器配置

依据 [BACKPACK-DOGS-26088801](https://github.com/deepseekv41flash/hd2-datamined/blob/master/docs/tables/BACKPACK-DOGS-26088801.md) 更新，适用于文档记录的 build 26088801。文档中的实机记录不等于本编辑器已对每种组合完成实机验证。

## 选择武器与载体

在对应背包战备页选择“无人机搭载武器”。这只修改无人机的 Mount 引用，不替换行为类，也不修改战备表的武器声明。

- 已有文档实测的副武器显示具体载体和前置条件；其他候选保留“实验性”标记。
- 副武器、支援武器按当前游戏目录全部纳入候选，不以文档中的少数示例作白名单。磁轨炮、纪元按配置排除。
- ARC-3 等需要松开扳机才发射的武器仍不列入候选；蓄力后自动发射的武器不因此排除。
- 有限弹药优先使用护卫犬或热狗。漫游车、K-9 没有常规装填，不能把“能开火”当作“能持续装填”。狗息的中毒行为也可能影响连续攻击。
- 武器模型、物理资源和射弹资源都需要加载。“原生挂载池”不保证资源一定已在场。

## 默认配件配置补全

逐把读取副武器、支援武器自己的默认配件 delta，展示可确认的实体射弹、备用射弹、弹匣模型、弹匣容量及备弹配置。没有对应 delta 的武器继续使用自己的原生实体数据，不套用其他型号的参数。

仅解析已确认的组件及字段布局；未实测的武器和载体组合仍标为实验性。缺少可信基准的字段不拿当前修改值冒充原值。

### P-19 与 P-2 示例

这两把武器的实体射弹原值为 0，玩家装备时由默认配件 delta 补齐；无人机直接挂载时不执行该建造流程。0 是合法休眠值，编辑器不会将其改称其他默认值。

在装备页打开对应武器，找到“无人机直读配置（实验性）”。例如：

| 武器 | 直读射弹 ID | 默认弹匣模型 |
| --- | --- | --- |
| P-19 救世主 | 296 | P-19 默认弹匣模型 |
| P-2 和平制造者 | 342 | P-2 默认弹匣模型 |

各项需要按需设置，不会自动替用户改写或安装资源补丁。其他型号如解析出自己的容量、备弹 delta，也会显示独立控制项。选好后，本页及无人机换装页的资源驻留检查会包含相应模型、物理资源与射弹依赖。

这些字段与使用同一武器实体的装备共享。可保存预设；恢复时还原可信游戏基准中的原始字节。弹匣引用以完整 64 位字节保存，选择器只允许该武器对应的模型。

## 装填量与备弹

文档已确认护卫犬直接填充弹匣，不检查或扣除备弹；该结论不能直接推广给所有无人机。

AC-8 的“每次装填数量”对应 WeaponRounds +92。原值 5、容量 10 时需要分两次装满；改为 10 后一次装满。该字段同时影响玩家手持和无人机。玩家与工事座位仍使用玩家弹药结算路径，不能据此忽略备弹。

资源写入成功后，仍需在游戏中检查模型、开火、装填和稳定性；音效绑定尚未完整定位。
