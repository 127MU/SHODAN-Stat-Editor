# Rust / Morrow 迁移状态

此分支版本号为 4.6.0。Rust / Morrow 迁移正在进行，当前不是纯 Rust 数据核心，部分旧版独立入口仍待迁移；发布范围必须如实描述。

- 已移除变种入口、代理后端、Steam 桥接和代理运行时打包。
- Rust 核心先迁移数值类型、不可变原值、冲突与边界校验。支持完整可表示范围，不人为限制质量、重力等参数。
- Flutter 界面从零编写，复用 Morrow 的 LiquidGlassSurface 和 shader，附带 AGPL 许可。
- upstream/4.6.0/manifest.json 记录上游输入的来源及哈希；已合并进定制核心，读取审计覆盖 69,502 项参数，尚需完成全部新功能的界面验证。

已连接：数据目录、数值修改与恢复、逐护甲被动、被动组合数值、装备预设、全局预设导入导出和分享码、游戏文字编辑、指令选择、资源补丁确认、写入预览及安装接口。4.6.0 新参数经统一行接口展示。

外观：9 个主导航；分类和参数四列；分类在弹窗编辑；MiSans 单字重子集保留 GBK 中英文、常用符号与源码字符；支持自定义背景，材质和字号持久化。数值仅显示到两位小数，不改底层精度。

本轮修复：文字接口缺少 code 校验；ExpansionTile 与滚动偏移共用 PageStorage 导致 double/bool 错误；显式字号不随主题缩放；护甲和弹窗未接入材质。Windows 崩溃符号指向 FlutterPlatformNodeDelegate::ChildAtIndex；使用直接 UIA provider、平台线程 UI、稳定卡片键及减少滑条重建作为规避措施，仍需持续实机稳定性验证，不能声称上游引擎空指针已根治。

待完成：预设描述/复制、车辆复制等独立交互入口；升级提示、MCP 和其他原有工作流的完整迁移与验证；清理旧 UI。此阶段仍保留 Lua 兼容数据层，不是纯 Rust 重写。

安装与诊断：安装前检查和写入均通过弹窗显示动态指示、实际阶段和文件计数；完成后显示结果并可导出日志。设置支持持久化诊断开关、只读文件/引擎/游戏目录检查及本地 JSON 报告。详细日志记录接口名、耗时和错误，不记录输入参数内容。测试安装替换写入函数，只验证生成的密封数据，不写真实游戏。

运行核心测试：cargo test --workspace。Flutter 入口：desktop/morrow/lib/main.dart。新 UI 已接通写入接口；所有自动测试使用隔离配置，不写入真实游戏。
