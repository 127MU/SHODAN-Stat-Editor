# 弹窗扩散动效与关闭卡顿修复

弹窗采用与深浅色切换一致的圆形扩散语言。有触发控件位置信息时，以该位置为扩散中心；没有来源控件时使用窗口中心。打开 300 毫秒，关闭 180 毫秒，分别使用减速与加速曲线。系统要求减少动态效果时跳过动画。

实现位于 `desktop/morrow/lib/motion.dart` 与 `glass_theme.dart`：

- `DialogApertureClipper` 使用 `reclip` 更新圆形裁切，不截取整页截图，不因半径改变重新布局参数表。
- 弹窗内容及标题、内容、操作区分别保留绘制边界。退场不再同时运行三组内容位移动画及描边追踪。
- 运动期间沿用现有玻璃过渡材质，暂停实时背景模糊与折射；静止后恢复用户选择的材质。
- `showMotionDialog` 等到 `route.completed` 后才将结果交回调用者。不能只等 `Navigator.push` 的 Future，因为它在开始 pop 时就返回，容易在退场期间触发页面刷新或提前销毁控制器。
- 参数输入在关闭失焦时仍提交数值，但表格刷新延后到退场结束；不将这个性能调整变成丢弃输入。
- 退场期间忽略重复点击。

`test/dialog_motion_test.dart` 检查扩散起点、覆盖范围、退出后的回调顺序、减少动画行为，以及退场连续帧是否重复调用内容绘制。`test/editor_test.dart` 检查未按回车就关闭时保存输入，并在退场结束后才重新读取表格。完整 Flutter 测试共 48 项通过，静态分析无问题。

这些测试证明状态与绘制失效行为符合预期，不代替不同显卡、驱动及高分辨率下的真实帧时间测量。
