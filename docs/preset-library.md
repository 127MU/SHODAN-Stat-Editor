# 预设库与 TXT 分享

版本：4.6.0-r5.1 dev。侧边栏独立「预设库」，无需在战备页面逐件寻找槽位。

## 使用

1. 在编辑区改好参数。进入预设库，选择「保存单件 / 多件战备」，搜索名称或 ID，勾选一件或多件；输入自定义名称保存。
2. 「保存整套修改」保存当前装备、敌人及护甲被动配置的参数预设。
3. 使用「切换预设」选择，查看包含的条目及参数变化；「读取预设」将修改放入编辑区，点击「写入游戏」才会安装。
4. 「导出当前预设」可保存 UTF-8 TXT 或复制文本；「导出全部预设」将本地预设库及已有的槽位/全局预设放到一个 TXT。
5. 对方可以将 TXT/JSON 拖入窗口、选择「导入文件」或「粘贴导入」。拖入未松开时有高亮与提示；松开后有识别动画，显示识别到的预设名称与战备，确认后保存。
6. 作者自定义名称随文件保留；导入后也可以重命名。相同名称、不同参数可同时存在，重复导入同一份内容不会重复创建。
7. 原先的装备槽位预设仍在装备工具栏；原全局预设可以从预设库的「原全局预设」进入，没有删除原功能。

## 格式与匹配

文本头 `SHODAN-SHARE 1` 后是 JSON；格式名 `SHODAN-PRESET-LIBRARY`，版本 1，groups 为命名的预设组合。每个组合包含 name 和 presets；presets 中沿用 `SHODAN-PRESET 1` 原始格式，携带 16 位条目标识及参数键，不能仅按显示名称猜测目标。

支持直接导入既有 `SHODAN-PRESET 1` 文本及 SSEO 分享码。名称、数值和文字配置不会经过两位小数的 UI 显示格式化。

新捕获的分享预设包含相对可信原版的实际差异（含已安装差异），原值未知时只捕获相对本次载入数据的改动，不凭空认定原值。与旧槽位预设的本次待写入捕获保持独立。

## 原子性与限制

- 每个组合读取前先完整准备所有参数、验证物理写入和共享配置冲突，再一次提交；一个组合可一次撤销。未知条目、参数歧义、共享配置互相冲突时不会部分应用。
- 导入多个组合时各组合独立验证，可以保存同一件战备的不同方案；不将独立方案混成一次读取。
- 导入只保存，不改变当前参数或游戏文件；读取只改变编辑草稿。
- 单批文本合计最多 8 MB；最多 50 个拖入文件。只接受 TXT/JSON 文件，不执行文件中的指令。
- 新预设库存储在配置目录的 preset-library.json，原有 native-presets.json 不被重写。预设库用原子文件替换保存。
- 外部改动已存在时，请先核对；该分享功能不替换资源包，不保证传送第三方 Mod 的资源或音效。
