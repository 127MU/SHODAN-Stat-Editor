# 编辑工作区与性能优化

## 编辑流程

1. 从分类或搜索选择装备，进入独立参数页。
2. 参数页可以切换「旧版 / 新版」，选择自动保存。旧版显示可收起的分组表单；新版把伤害、射击、弹药、操控等分类显示为彩色图标卡片，点击「打开」在弹窗中编辑该分类。
3. 恢复基准显示在参数标题旁，下面区分启动文件值和待写入值；不能确认的原版来源不会标为游戏原版。回车或离开输入框保存；共享字段提前显示部分受影响条目，可展开完整名单。
4. 分组可独立收起，也可全部展开或收起；预设仍属于当前选择的装备。
5. 写入前查看变化预览，确认后在当前窗口查看处理阶段和耗时。

## 本轮实现

- 旧版分组改为 ListView 按可见区域创建，保留小范围缓存；收起后卸载该组字段并实际缩短卡片高度。新版只显示分类卡片，打开弹窗后才创建编辑控件。搜索仍基于完整条目数据，不依赖控件是否已加载。
- 同一装备的选项刷新会保留当前分组、滚动锚点和弹窗位置，避免载具挂载等选择变更后跳回顶部。
- 首页和参数分类卡片底部使用「打开」按钮，不使用装饰性进度条。
- 普通数值与开关保存、恢复后调用 `rows_delta`，按照底层共享字段关联更新当前条目；涉及射弹、结构选择和指令的操作仍刷新完整结构。
- 已修改过滤和计数通过单独版本通知更新，普通编辑不重建现有输入框。
- 磨砂及液态玻璃增加省电、均衡、高品质档位。省电减少模糊与折射并停止流动；均衡在滚轮、触摸滚动和滚动条拖动期间暂停流动，停下 220 ms 后恢复。
- 外观设置增加常用/高级切换，保留原有个人主题和细调；材质性能档位随设置和个人主题保存。
- 变种先选择「仅叠加效果」「开放解放作战」「防守作战」，再展示所需敌人、来源和时长；缺少必要配置时提示并阻止保存。
- 写入弹窗显示当前阶段、阶段进度、历史阶段耗时和总耗时。底层新增备份、生成、提交和验证通知；通知观察者失败不会中断文件提交。

## 验证边界

局部刷新测试在独立配置中比较 293 项完整/局部读取与恢复结果，其中包括 134 项开关操作；不写入游戏目录。
界面回归检查控件保存后保持同一实例，且首屏只创建部分参数控件。
写入阶段测试只操作临时模拟目录，检查观察者报错不会导致半途中止。
GPU 帧耗时仍依赖具体显卡与用户背景图片，本轮不宣称固定的帧率提升。

## 编辑安全与写入反馈

- 参数旁直接显示共享影响对象，悬停查看完整名单，点击查看条目类型；使用当前有效引用关系，不按名称猜测。
- 保留本次启动最近 100 次参数事务，支持数值、开关、选项、战备指令、恢复、护甲被动数值和护甲组合的撤销/重做。新编辑清空重做分支，加载预设后清空旧历史。资源补丁的实际安装/移除不参与撤销。
- 撤销前核对当前字段仍为预期值，避免覆盖其他操作；仅回放该事务涉及的字段和覆盖记录。修改记录入口列出操作和字段数。
- 恢复基准来自备份/版本参考数据；启动文件值来自独立的只读快照，可能已经被其他修改器改过；待写入值是编辑中的工作副本。动态、资源引用及不支持映射的字段明确显示不适用或未知，不回退成假原值。
- 写入弹窗显示阶段、当前文件/资源包、阶段进度与耗时；资源读取期间按条目批次通知。
- 相同游戏文件在外部修改检查之后跳过暂存与替换；资源补丁在完整比较主文件及伴生流后跳过重复写入。仍进行必要的读取、构建和比较，不宣称所有依赖扫描都已省略。
- 验证只使用独立配置和临时模拟目录，不写入真实游戏文件。当前覆盖 98 次数值/开关往返、26 次选项往返、2 项护甲回放以及重复安装/失败保护测试。
