# 编辑流程与数值状态

适用：4.6.0-r5.1 dev；更新：2026-11-09（香港时间）。

## 日常编辑

1. 选择左侧分类，搜索名称、型号或 ID。目录支持「仅已修改」，同类载具/敌人可先选择关联条目。
2. 打开条目后，从四列参数分类卡片进入弹窗。搜索基于完整参数数据，不依赖当前可见控件；切换条目时不沿用上一个条目的参数搜索。
3. 输入后回车或点击输入框外确认；开关、选择器直接提交到编辑草稿。护甲被动弹窗关闭前等待保存结果，失败时保留输入供重试。
4. 查看原值、当前值和共享影响。恢复按钮使用可信原版值；修改记录、撤销/重做、射击引用链和资源诊断位于参数工具栏。
5. 完全退出游戏，预览本次写入，再确认。当前窗口的进度弹窗显示真实处理阶段和结果；成功后重新启动游戏。

## 显示精度与保存精度

浮点数通常最多显示两位小数，完整精度由 Rust 工作区保留。仅聚焦、离焦或查看不会将显示值写回；明确回车以及实际编辑后的离焦按完整数值比较。接近 2 而显示为 2 的值可以直接提交 2，不需要补尾数。

实际存储类型仍有边界：整数需要可表示，浮点值需要有限，引用需要有效。单块表的哈希校验可能在用户允许时微调已修改浮点值的低位；安装结果中的实际修正值与界面显示精度是不同概念。

## 修改、已有差异和原值

- 原值来自匹配版本的可信基准；当前游戏文件可能已含旧工具或 Mod 的修改。
- 「与原值不同」表示当前数据与基准不同，不表示一定是本次编辑造成；不可将其自动收为新默认值。
- 「整理已有差异」先预览，支持选择恢复项，并保护编辑器已记录的修改；确认只暂存，仍需写入游戏。
- 多个条目可共享底层记录。改动伤害、射弹、爆炸或资源引用前应检查共享影响，而非只看名称相似程度。

## 保存和分享

侧边栏「预设库」管理命名方案，支持单件 / 多件战备、整套当前修改、TXT 导出、复制文本、文件拖入和粘贴导入。名称与稳定标识随文本保留。

导入只保存到预设库；选择后「读取预设」应用到编辑区，再「写入游戏」。多件组合在所有参数验证通过后一次提交，可一次撤销；不会因为导入了一个方案就自动清空其他编辑。整套资源包、音效或第三方 Mod 文件不随参数预设发送。详见 [预设库](preset-library.md)。

原有装备槽位预设仍在当前装备工具栏，原全局预设入口保留在预设库中。

## 异常与验证边界

坏表会隔离并显示文件名，其他数据可浏览。先在设置运行 [自动修复](automatic-repair.md)，仍有问题时导出 [诊断日志](diagnostic-logging.md)。安装及恢复失败都保留对应强制入口，但仍执行数据、版本、备份及访问检查。

滚动、卡片进入和弹窗过渡使用统一动效；减少动画设置应即时生效。具体帧率与背景、显卡和窗口尺寸有关，不承诺固定帧率。

离线测试验证参数读写、持久化、预设往返与文件恢复。弹道、音效和实验性组合的游戏局内效果仍需对应 build 的实机验证。
