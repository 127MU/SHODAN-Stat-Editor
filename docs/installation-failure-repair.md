# 安装失败原因及自动修复范围

版本：4.6.0-r5.1 dev，更新日期：2026-11-09（香港时间）。

“自动修复完成”指本次检查没有剩余阻塞，不代表能处理任意外部 Mod 或未知游戏版本。修复操作保留备份，结果和导出日志会说明未解决项。

## 原因与处理

| 原因 | 自动修复行为 | 仍需用户处理的情况 |
|---|---|---|
| 安装中断、遗留未提交事务 | 依据原事务的前后指纹恢复，并备份恢复前内容 | 文件已被第三方再次修改、事务或备份损坏时不覆盖 |
| 无效 JSON 草稿阻塞启动 | 完整备份草稿后解除启动阻塞 | 过大、不可读取、来源已变化的草稿不猜测应用 |
| 派生战备与当前数据不符 | 备份并解除失效生成登记，重载当前数据 | 实际选择的重复附赠战备或不兼容配置仍需调整 |
| 已由外部操作恢复到安装前文件，但旧数值登记仍在 | 只有当前密封文件与已登记安装前备份逐字节一致时，事务化清理过期登记；不改游戏文件 | 当前文件仍是其他内容时保留它，报告冲突 |
| 本程序已管理的数值文件被删除 | 核对备份 SHA-256、密封格式和当前游戏 DLL 预期哈希后补回原文件，并清理过期登记 | 未登记、缺备份、损坏备份、旧版本备份不自动补造 |
| 数值表无法解密或 LDLD 结构损坏 | 隔离坏表并保留其余分类；先备份，再从匹配当前版本的已校验安装备份或随附原版数据恢复 | 没有可信来源时保留文件，提示 Steam 完整性验证；不生成假表 |
| 主实体文件被删除，启动阶段无法建立工作区 | 修复入口允许定位有 game.dll 的游戏目录，先核对版本及自有备份，再恢复缺失文件并打开工作区 | 不能借此跳过游戏版本检查或读取错误 |
| 完全缺失的自有资源补丁槽位 | 清理失效登记，必要时补齐已确认中间缺号，保留更高槽位加载链 | 原模型、特效和音效不会凭空恢复，需要重新安装相应驻留资源 |
| 驻留文件部分缺失、伴生文件被替换、外部 Mod 占槽 | 检查并报告来源和指纹，不冒充修复成功 | 核对来源后恢复对应 Mod，不能自动删除外部补丁腾槽 |
| 修改器打开后磁盘数据再次变化 | 重新读取工作区，保留冲突草稿；重新生成预览 | 不在旧快照上强行写入；仍有外部修改时需确认处理 |
| 原始备份缺失或被篡改 | 明确报告，不继续覆盖已管理文件 | 需要可靠备份或匹配版本的游戏文件；不会用当前修改值伪造原版 |
| Windows 拒绝访问/文件占用（5/32） | 报告目标路径和系统错误码 | 退出游戏及编辑工具，检查对应目录权限、只读与占用；不自动改 ACL 或强行解除占用 |
| 磁盘空间不足（112） | 保留事务证据，提示释放空间后恢复 | 不自动删除其他文件 |
| 程序、参数目录或游戏版本不匹配 | 拒绝猜测布局及写入 | 使用匹配版本和正确游戏副本；自动修复不下载未知布局 |
| 哈希校正空间不足、整数修改没有校验盐 | 扩展既有保留区候选搜索；特定单块射弹文件可在预览告知并确认后借用初速低位校正 | 自动修复不跳过哈希检查、不任意改变格式长度，仍不可解时保留失败日志 |

## 强制操作与浮点输入

安装失败、预览异常或预览存在阻塞时，均可找到「强制写入」；恢复失败均可找到「强制恢复」。按钮触发的是带备份的强制流程，不绕过版本、损坏表、磁盘快照、备份完整性或文件占用检查。

浮点数输入 `2`、`2.0`、`2e0` 或 `2.000000001` 可能转换成相同的 f32 位模式。显示为整数不意味着字段变成整型。r5.1 已将两位小数的显示值与完整保存值分开，回车和实际编辑后的离焦会按完整值提交，仅查看不取整写回。

哈希校验空间不足是独立问题；强制写入允许已修改浮点值的低位修正并报告实际结果。补写一串小数不能替代格式与校验检查。

## r4.2 修正记录（历史）

1. 旧修复流程没有重核数值安装登记，可能检查完成后再次安装仍报“已被其他工具修改”。现在区分精确外部恢复、缺失文件和真实外部修改，分别处理。
2. 原来的游戏目录识别和加载都要求实体文件存在；恰好缺少它时根本进不了恢复路径。修复专用定位允许缺失实体文件，但保持 DLL build、备份指纹及当前版本哈希校验。
3. 写入已管理文件前重新核对原始备份，防止继续安装后失去可靠恢复来源。
4. 文件读取、事务创建、写入、目标替换和目录访问错误现在提供目标路径、系统错误码与底层说明；导出会隐藏个人目录。
5. 安装失败及修复结果提供分类和下一步建议，诊断报告包含最近一次失败分类和完整检查结果。

## 验证方式

Rust 单元覆盖精确外部恢复、从完整备份补回缺失文件、拒绝其他版本和损坏备份、保留真实外部修改。桌面 RPC 使用隔离游戏副本复现“删除已管理实体文件 → 启动失败 → 自动修复 → 再次安装”和“外部还原文件 → 清理过期登记 → 再次安装”。真实 Steam 游戏目录仅作读取。

详细日志格式和操作方法见 [诊断日志](diagnostic-logging.md)。前一轮原值、准星和驻留复查见 [本轮审查](audit-r41-20261108.md)。
